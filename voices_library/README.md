# مكتبة الأصوات الخاصة - 28 صوت محفوظ

تم حفظ جميع الأصوات التي اخترتها من الاقتراحات (28 صوت) في هذه المكتبة.

## الملفات
- `library.json` — يحتوي على جميع voice_id مع تفاصيل كل صوت
- `samples/` — عينات صوتية مسجلة لكل صوت (10 عينات مولدة حالياً، الباقي يمكن توليده لاحقاً بنفس voice_id)
- `index.html` — صفحة معاينة لجميع الأصوات

## كيفية الاستخدام
لاستخدام أي صوت في المستقبل:

```python
generate_speech(
  voice_id="voice-19",  # مثلاً الصوت البريميوم
  text="نصك هنا...",
  file_path="output.mp3"
)
```

## قائمة الأصوات
- voice-00 إلى voice-27 (28 صوت)
- الأصوات 20-27 هي الأكثر غموضاً وسينمائية بأسلوب ناشيونال جيوغرافيك
- voice-19 هو PREMIUM المستخدم في النسخة البريميوم السينمائية

تم توليد 10 عينات صوتية كاملة. باقي العينات يمكن توليدها لاحقاً باستخدام نفس voice_id لأنها محفوظة في النظام. جميع voice_id صالحة للاستخدام في أي وقت.
